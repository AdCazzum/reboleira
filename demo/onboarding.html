ENSight onboarding wizard (Task 16)

Dev/test-only harness - NOT part of the shipped extension. Standalone Preact page that does the real end-to-end profile setup: connect wallet → verify human (World ID) → fill profile → encrypt & upload to 0G Storage → write the pointer + attestation to ENS on Sepolia. Uses the real src/core/crypto.ts, src/services/world-id.ts, src/services/zerog-storage.ts and src/config.ts (no copies, no mocks).

Serve this directory over http://localhost (not file://) so MetaMask injects window.ethereum reliably. Use node scripts/onboarding-server.mjs from the repo root, then open http://localhost:8080/onboarding.html - a generic static server (e.g. npx serve demo) will NOT work for Step 2 (World ID): that step fetches POST /rp-context from the same origin, which only scripts/onboarding-server.mjs provides (it signs the request in Node, since @worldcoin/idkit/signing's signRequest() refuses to run in a browser - see that script's header comment), and a generic server may also serve .wasm with the wrong MIME type, which breaks idkit's WASM module. Requires a .env filled in per .env.example before building (see Build below) - CONFIG is inlined at build time - and WORLD_RP_SIGNING_KEY/WORLD_RP_ID set (env or the same .env) before starting the server, for Step 2 specifically.
