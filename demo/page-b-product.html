Overview

NimbusKey Pro is a hardware authentication device supporting FIDO2, WebAuthn, U2F, and OTP protocols, designed for engineers and security teams who need phishing-resistant multi-factor authentication across cloud consoles, source control, and VPN endpoints. The device stores private keys in a secure element and never exposes them to the host operating system.

Unlike software-based authenticators, NimbusKey Pro requires physical presence for every authentication event, which mitigates remote credential theft even in the event of a fully compromised host machine. The device is rated IP68 for dust and water resistance and is built to withstand daily carry on a keyring.

Technical specifications

  • Protocols: FIDO2, WebAuthn, U2F, TOTP/HOTP
  • Connectivity: USB-C and NFC (ISO/IEC 14443)
  • Secure element: EAL6+ certified
  • Durability: IP68, crush-resistant up to 2kN
  • Physical: 45 x 18 x 4 mm, 3.4 g
